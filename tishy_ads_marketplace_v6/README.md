# Tishy Ads Marketplace v2

A much more complete Flask marketplace with persistent accounts and listings.

## Features
- Create accounts and securely hashed passwords
- Sign in and sign out
- Publish real listings into SQLite
- Listing detail pages
- Favourites stored per account
- Personal account dashboard
- Seller messaging endpoint
- Search, sorting, 18 categories and Nigerian locations
- 15 seeded marketplace listings
- Remote product images with descriptive alt text
- Responsive black/green design

## Run
pip install -r requirements.txt
python app.py

Open http://127.0.0.1:5000
